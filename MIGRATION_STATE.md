## Текущий переход

Проект переводится на статический экспорт Next.js в папку `out/` для последующей загрузки на виртуальный хостинг Beget.

## Следующие этапы

1. Закрыть клиентские и юридические блокеры из `PREDEPLOY_BLOCKERS.md`.
2. Повторно собрать архив только при необходимости и сверить его по `BEGET_DEPLOYMENT_CHECKLIST.md`. SHA-256 подтверждает целостность конкретного созданного ZIP; после новой сборки он может измениться из-за build ID и метаданных.
3. Только после этого разместить содержимое `out/` в `public_html` на Beget и проверить production-доставку заявок.

## Схема заявок

`статический frontend → /api/lead.php → info@remontvariator.ru`.

Публичная Telegram-кнопка остаётся отдельной ссылкой для самостоятельного обращения и не связана с формами. Honeypot скрыт от пользователя, а rate limit ограничивает 5 реальных попыток за 10 минут на `REMOTE_ADDR`; временно хранится только SHA-256-хеш IP и отметки времени, без содержимого заявок. До размещения на Beget нельзя подтверждать доставку email.
