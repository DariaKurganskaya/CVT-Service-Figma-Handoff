## Расхождения с GitHub main

GitHub `main` находится на commit `2ef3324d4d655a8cc9ac95316ca75a2da646d976` и не соответствует опубликованному preview.

- `app/page.tsx`, `app/globals.css` и `app/lead-form.tsx` в рабочем исходнике новее; актуальная версия содержит последние мобильные исправления, композицию CTA, юридические ссылки и визуальные формы без отправки.
- `app/mobile-menu.tsx`, `app/layout.tsx`, `next.config.ts` и `package.json` совпадают с GitHub `main`.
- В актуальном `public` есть дополнительные используемые изображения и SVG, а `public/og.png` отличается от версии в `main`.
- В актуальном footer юридические подписи являются ссылками на `/privacy-policy` и `/cookie-policy`; в GitHub `main` это обычный текст.
- Страницы `app/privacy-policy/page.tsx` и `app/cookie-policy/page.tsx` отсутствуют и в актуальном исходнике, и в GitHub `main`. Поэтому ссылки присутствуют в preview, но оба URL отвечают `404`.

## Проверка сборки и тестов

- Production-сборка проходит успешно.
- Имеющийся тест `tests/rendered-html.test.mjs` не проходит: он ожидает старый `NEXT_PUBLIC_LEAD_FORM_ENDPOINT`. Актуальный `app/lead-form.tsx` преднамеренно предотвращает отправку формы через `preventDefault()` и не использует endpoint. Тест не исправлялся в рамках фиксации состояния.
